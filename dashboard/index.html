THE EXPERIMENT, EXPLAINED

Built around CRISP-DM

↓ Model results JSON
01 / Business understanding

Estimate startup profitability from spending and location. Compare predictive accuracy with model simplicity, without treating associations as investment advice.

02 / Data understanding

50 records, three numerical spending variables, one categorical state, and Profit as the target. This small sample limits generalization.

03 / Data preparation

80/20 split with random_state=42. OneHotEncoder drops California and ignores unknown categories. Encoders are fit on training folds; state categories are declared from the dataset specification.

04 / Modeling

Pearson, mutual information, scaled RFE, RFECV, and LassoCV select encoded columns. Every selected subset is refit with ordinary LinearRegression in original units.

05 / Evaluation

Five outer training folds repeat selection and OLS fitting. RFECV and LASSO tune inside each outer training fold. The recommendation minimizes mean outer-fold RMSE; ties prefer fewer columns. Test scores never select the recommendation.

06 / Deployment

Python exports model parameters and diagnostics to JSON. This static dashboard computes predictions locally and can be served on GitHub Pages without a Python backend.

Interpretation limits. Model search can make the winning CV score optimistic; fold SD is not a confidence interval. LassoCV scales on each outer training fold before its internal alpha search, so internal tuning shares scaling statistics; outer validation remains isolated. RFECV's internal curve is a tuning diagnostic, separate from outer evaluation. Adjusted R² is reported for training data only.
